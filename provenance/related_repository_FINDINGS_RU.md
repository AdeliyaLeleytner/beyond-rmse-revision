## 4. Conformal использует отдельный протокол

`src/ml_utils.py:633–704`:100 раз из holdout случайно отбираются500 молекул для calibration, интервалы оцениваются на оставшихся. Для полного теста2537 это500/2037. Само по себе такое деление не доказывает утечку тестовых меток в точечную модель или автоматическое нарушение обменности. Описание эксперимента должно соответствовать процедуре. Функция возвращает средние ширины интервалов, но не эмпирическое покрытие; по одной ширине нельзя оценить калибровку.

## 5. Дополнительные ограничения

- Название ADME обозначает68 смешанных признаков ADMETLab, включая физико-химические свойства, правила drug-likeness и ADME-предсказания. Это не68 только экспериментальных фармакокинетических показателей. hERG/Respiratory/Neurotoxicity-DI не входят в этот68-признаковый список. Целевой LD50 в него также не входит.
- BBB-фильтр в features_utils.py вычисляется из MW/logP и структурных TPSA/HBD/rotatable bonds, а не из смещённого столбца ADMET `BBB`. Ошибку ADMET нельзя автоматически переносить на состав BBB-подвыборки. Сравнение её RMSE с полным тестом всё равно не измеряет эффект специализации; нужен один и тот же тест.
- PCA в training notebook обучается на всём train+val до GroupKFold. Фолды внутренней CV поэтому участвуют в вычислении преобразования. Внешний test при этом в PCA.fit не подаётся. Рекомендуется PCA внутри каждого CV-fold.
- Финальный fit использует90% train_val и10% для early stopping, но metadata сообщает n_samples=len(train_val) и fitted_on=train_val; отдельного переобучения на всех train_val после выбора числа деревьев нет. Это неточность отчётности, не свидетельство тестовой утечки.
- Проверка пересчёта −log10LD50 из log10(mg/kg) и MW прошла: максимальное абсолютное расхождение1.33e−15. Среди основных canonical isomeric SMILES нет точных дубликатов. Это ограниченная проверка внутренней согласованности, не аудит лабораторных источников LD50.

## Дополнение: проверка потребителей готового датасета

Проверены все4 notebooks и функции src: downstream объединения с исходным ADMET по SMILES нет. 02_model_training читает FINAL_DATA_PATH, выбирает готовые числовые столбцы. 03_shap_analysis/prepare_model_data читают ту же матрицу, отбирают строки по ligand_id из split CSV. Неправильных ассоциаций в опубликованных split CSV: train1102/8043, val259/2071, test317/2537. При воспроизведении выбора fit/early-stopping текущего кода:1217/9095 и144/1019. В200-молекулярной SHAP-подвыборке ADME:29 неправильных строк. Это подсчёт входов по коду, не утверждение о восстановленной истории каждого .pkl.

Изолированная подстановка68 исправленных ADMET-столбцов на12583 общих проверенных ID меняет1662 строки ADME-матрицы и ни одного входного значения Plain/Baseline/PCA. Число1662 меньше1678, поскольку проверка ограничена общими химически подтверждёнными ID; никакого противоречия с полным числом ошибочных ассоциаций нет. BBB-флаг и целевая переменная на общих ID совпадают. PCA использует только protein scores для преобразования, BBB pass — Baseline-список признаков. Для тех же молекул и фиксированных моделей исправление только ADMET не меняет прогнозы моделей без этого блока. Пересборка всей когорты/разбиений может изменить их результаты отдельно.

ADME затронута при оптимизации, fit, early stopping и тестировании; следовательно, её общие метрики, интервалы на её остатках и все SHAP-вклады этой модели требуют обновления. Влияние обучения на неправильных строках может распространяться на прогнозы для всех тестовых молекул, а не только317 ошибочных тестовых строк. Прямые изменения RMSE именно этой версии моделей здесь не измерялись.

При сравнении с прежней исправленной матрицей обнаружено независимое различие: этот репозиторий заменяет положительные docking scores нулями. На общих ID различаются36 protein-столбцов в1145 строках; после clip(upper=0) они полностью совпадают с прежними. Поэтому прежние пересчёты Beyond-RMSE нельзя называть изолированным измерением ADMET-эффекта в этом репозитории.
