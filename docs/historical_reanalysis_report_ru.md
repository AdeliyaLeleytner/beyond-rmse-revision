## Главный результат аудита данных

Обнаружены две разные проблемы, которые нельзя объединять в одну «опечатку».

1. В исходной Table 2 действительно использованы 8 096 / 2 024 / 2 530 молекул, всего 12 650. Из теста удалён ligand_id 1298 (PubChem CID 120203). Сохранённое обоснование исключения ссылается в том числе на ошибку прогноза; независимого основания считать соединение невалидным не найдено. В новых расчётах оно включено. Простое возвращение этого соединения на старой матрице меняет RMSE с 0,500575 до 0,501584.
2. Аудит соединения исходных таблиц выявил сдвиг ADMET-блока, затрагивающий 1 678 опубликованных ассоциаций compound–ADMET. В исходной таблице 12 652 записи; фактически невалидный ADMET-результат относится к ligand_id 11434, тогда как публичный master исключает валидный ID 9116. Все 120 ADMET-столбцов публичной таблицы численно совпадают с последовательностью отфильтрованного ADMET-вывода, но соединения для участка ID 9117–11434 сопоставлены со сдвигом. Это подтверждено таблицами и сохранившимся raw-выводом из Git. Само по себе несовпадение 2 079 строк SMILES не является числом ошибок: часть различий вызвана представлением зарядов.

Исходный журнал API-запросов не найден. Поэтому строки не принимались за правильные только на основании позиции. Сопоставление восстановлено по исходным ID с независимой проверкой химической идентичности: 12 193 точных canonical isomeric SMILES + 391 уникальная в обеих таблицах незаряженная isomeric-форма. 67 неоднозначных преобразований структуры исключены; стереохимия не удалялась, таутомерные/редокс-преобразования не принимались за доказательство идентичности. Невалидный ID 11434 исключён, валидный ID 9116 возвращён. Основная проверенная выборка: **12 652 − 1 − 67 = 12 584**. Строгая чувствительность: **12 193** точных совпадения. Это не повторный запрос к ADMETlab и не доказательство правильности самих внешних предсказаний.

## Биологический сигнал и чувствительность

Отбор трёх phenotype-маркеров повторён только по proper-training labels, с 30 внутренними групповыми разбиениями. Во всех пяти основных и всех пяти строгих разбиениях выбраны hERG, Respiratory, Neurotoxicity-DI. Масштабирование координат и границы квадрантов также оцениваются на train. Проверка с заменой всех calibration/test labels не изменяет таблицу отбора.

Во всех пяти основных разбиениях Joint имеет меньший interval score, чем локализация по одному прогнозу yhat; средняя разница −0,0497. По сравнению с MW/logP Joint лучше в четырёх из пяти, средняя разница −0,0318. Все 25 точечных сравнений с перестановками биологических координат дают меньший score у Joint, средняя разница −0,0848. Некоторые отдельные bootstrap-интервалы включают ноль. Это поддерживает полезность биологических координат в этих данных, но не доказывает универсальное преимущество или молекулярный механизм.

В каждом из пяти разбиений ширина возрастает в порядке Pheno+ MIE+ → Pheno+ MIE− → Pheno− MIE+ → Pheno− MIE−. Ширина Pheno+ MIE+ в primary seed 42 — 1,2472, Pheno− MIE− — 1,7964. Такой рисунок ширин сохраняется, но равномерное покрытие по областям не сохраняется.

Проверки distance cutoff 0,3 / 0,5 и bandwidth 0,6 / 1,2 сохранены без выбора лучшего по тесту. На строгой выборке 12 193 точных совпадений средний RMSE confidence-модели **0,5251**, локальное покрытие **89,36%**, глобальное **90,26%**; средние ширины **1,5247** и **1,6324**. Основная картина не объясняется одним включением 391 пары заряженных форм. В дополнительном, назначенном после обнаружения нового ранжирования моделей контроле на строгой выборке ADME также лучше Plain во всех пяти разбиениях: средний RMSE 0,49284 против 0,51677. Этот контроль отмечен как последующая проверка, а не заранее заданный эксперимент.

Нулевое пересечение кластеров не устраняет все похожие пары. В primary seed 42 медиана максимального Tanimoto(test,train)=0,500, P90=0,6604; **1,82%** test имеют аналог с Tanimoto≥0,8, максимальное сходство 0,9310. Идентичных кластеризационных bit-векторов между train и test нет. Полные распределения сохранены в `repaired/similarity/`.

## Глобальные модели: вывод статьи изменился

Повторно обучены Baseline, PCA, ADME, Plain и BBB pass на всех пяти основных разбиениях. Использованы опубликованные фиксированные гиперпараметры; нового Optuna-поиска не было. Early stopping выполняется на внутреннем 10% group holdout proper train; imputation/PCA обучаются только на внутренней fit-части. После выбора числа деревьев модель переобучается на proper train. Calibration выделена отдельно; интервалы 80/90/95% не калибруются на тестовых данных.

ADME лучше Plain по RMSE во всех пяти основных разбиениях. Следовательно, исходное утверждение «Plain лучше, ADME сопоставима» нужно заменить. Это сравнение конкретных конфигураций с разными опубликованными гиперпараметрами, не изолированная причинная оценка добавления признаков. BBB pass нельзя ранжировать напрямую с полновыборочными моделями: её тестовый домен уже. Предсказания позволяют сравнить BBB pass с Baseline на одних и тех же BBB test IDs; парные результаты сохранены.

Пересчитаны SHAP для primary seed 42, по 512 тестовым молекулам на модель; проверена аддитивность относительно прогноза. Для Figure 3 использовано **mean(abs(sum(group SHAP)))**, как в исходном notebook, а не сумма абсолютных вкладов. В ADME-модели группы: ADME 0,2678, PhysChem 0,0837, Fingerprints 0,0688, Proteins 0,0383. SHAP описывает поведение модели и не доказывает причинный токсикологический механизм. Утверждение о «modality bias» как установленном объяснении требует смягчения.
